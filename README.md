
# Stock Market Trend Prediction
## 1. Project Overview
This project implements a deep learning model to predict stock market trends for the next 5 candles (data points). The model classifies trends into three categories:

Uptrend : All 5 future candles are green (Close > Open)

Downtrend: All 5 future candles are red (Close < Open)

Neutral: Mixed pattern of green and red candles
## 2. Objective
Develop a time-series prediction model using deep learning techniques to forecast short-term stock market trends based on historical price data and technical indicators.

## 3. Dataset
File: large_32.csv

Size: 92,514 rows x 26 columns

Features: Historical stock data with technical indicators including:

Price data: Open, High, Low, Close, Volume
Moving Averages: SMA 5, SMA 10, SMA 50
Momentum Indicators: RSI 14, MACD LINE, MACD SIGNAL, MACD HISTOGRAM
Volatility Indicators: Bollinger Bands (SMA, Upper, Lower)
Pattern Indicators: Alligator (Jaw, Teeth, Lips)
Other: EMA 9, KAMA, KAMA COLOR, ATR, RMA 14, SMOOTH MA 14, WMA 14
## 4. Model Architecture
LSTM-Based Deep Learning Model
Input Layer: (30 timesteps, 25 features)
↓

LSTM Layer 1: 128 units + Dropout (0.3) + Batch Normalization
↓

LSTM Layer 2: 64 units + Dropout (0.3) + Batch Normalization
↓

LSTM Layer 3: 32 units + Dropout (0.3) + Batch Normalization
↓

Dense Layer 1: 64 units (ReLU) + Dropout (0.3)
↓

Dense Layer 2: 32 units (ReLU) + Dropout (0.2)
↓

Output Layer: 3 units (Softmax) → [Downtrend, Neutral, Uptrend]
Total Parameters: ~145,859
## 4.1. Why LSTM?
Temporal Dependencies: LSTMs are designed to capture long-term dependencies in sequential data

Memory Cells: Can remember important patterns from past candles

Gradient Flow: Better gradient flow compared to vanilla RNNs, preventing vanishing gradients

Proven Track Record: Widely successful in financial time-series prediction tasks
## 5.Technical Implementation
## 5.1. Data Preprocessing
Converted date-time format and sorted chronologically

Handled missing values using forward-fill and backward-fill

Normalized all features using StandardScaler
## 5.2. Label Generation
Labels were programmatically generated by analyzing the next 5 consecutive candles:

Python- 
- If all 5 candles are green → Label = 2 (Uptrend)
- If all 5 candles are red → Label = 0 (Downtrend)
- Otherwise → Label = 1 (Neutral)
## 5.3. Sequence Creation
Window Size: 30 past candles

Created sliding windows for time-series input

Each sample contains 30 timesteps of historical data
## 5.4. Train/Validation/Test Split
Training: 70% (64,735 samples)

Validation: 15% (13,871 samples)

Test: 15% (13,873 samples)

Important: Time-series split (no shuffling) to prevent data leakage
##5.5. Class Balancing
Challenge Identified: The dataset is heavily imbalanced:

Downtrend: 2,654 samples (2.9%)

Neutral: 87,120 samples (94.2%)

Uptrend: 2,735 samples (3.0%)

Solution: Applied class weighting to balance learning:

Downtrend weight: ~12.34

Neutral weight: ~0.35

Uptrend weight: ~10.95

This ensures the model doesn't just predict "Neutral" for everything.

## 6. Model Training
## 6.1. Training Configuration

Optimizer: Adam (learning rate = 0.001)

Loss Function: Sparse Categorical Crossentropy

Batch Size: 32

Max Epochs: 100

Callbacks:

Early Stopping (patience=15, monitor='val_loss')

Learning Rate Reduction (factor=0.5, patience=7)
## 6.2. Training Strategy

Used validation loss for early stopping to prevent overfitting

Dynamic learning rate adjustment based on plateau detection

Restored best weights after training completion.
## 7. Evaluation Metrics
The model is evaluated using multiple metrics suitable for multi-class classification:

Accuracy: Overall correctness of predictions

Precision: Accuracy of positive predictions per class

Recall: Coverage of actual positive cases per class

F1-Score: Harmonic mean of precision and recall

Confusion Matrix: Visual representation of prediction performance

## 9. Key Insights and Assumption
## 9.1. Insights

Imbalanced Data: Stock markets tend to stay neutral most of the time, with clear trends being rare.

Technical Indicators: Multiple indicators provide complementary information about market behavior.

Window Size: 30 candles (~30 minutes to hours depending on timeframe) captures short-term patterns.

Class Weighting: Essential for learning minority classes in highly imbalanced datasets.
## 9.2. Assumptions

Time-series Nature: Data is sequential and temporal dependencies exist.

No Look-Ahead Bias: Strict chronological split to simulate real-world scenario.

Stationarity: Technical indicators help normalize non-stationary price data.

Edge Cases: Very early sequences (first 30 rows) cannot generate predictions due to window requirement.

## 9.3. Challenges Faced

Class Imbalance: Solved using class weighting

Overfitting Risk: Mitigated with dropout layers, batch 
normalization, and early stopping

Computational Cost: LSTM layers are computationally expensive; 
optimized with appropriate batch size
